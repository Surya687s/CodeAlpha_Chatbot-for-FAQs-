# 🤖 Surya Datta FAQ Chatbot

An intelligent and interactive FAQ Chatbot built using Python, NLP, and Machine Learning techniques.  
This chatbot can understand user questions, match them with the most relevant FAQ using cosine similarity, and display accurate responses through an attractive graphical interface.

---

# ✨ Features

✅ Beautiful Chatbot UI using Tkinter  
✅ NLP Text Preprocessing using NLTK  
✅ Intelligent FAQ Matching  
✅ Cosine Similarity Based Responses  
✅ Scrollable Chat Interface  
✅ Enter Key Support  
✅ Easy-to-Customize FAQ Dataset  
✅ Fast and Lightweight Application  

---

# 🛠️ Technologies Used

- Python
- Tkinter
- NLTK
- Scikit-learn
- NumPy
- JSON
